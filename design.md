# Design — Ivan Alcantara Portfolio

Locked Hallmark system for this site. Prefer consistency across pages.

## Genre
editorial-technical (recruiter-facing student portfolio)

## Macrostructure family
- Marketing / home: Workbench — typography-led hero, case-study work first, stack as grouped systems
- Content / case study: Long Document — problem → flow → contribution → stack → live

## Theme
- Paper: near-black graphite `#0a0b0d`
- Ink: off-white `#f2f2f0`
- Muted: `#8a8f98`
- Rule: `rgba(255,255,255,0.08)`
- Accent: cool signal `#5eb8e8` (use sparingly — never glow wallpaper)
- Focus: `#5eb8e8` at ≥3:1

## Typography
- Display: Syne (roman, weight 600–700)
- Body: Geist Sans
- Mono: Geist Mono — labels only, not ALL CAPS walls

## Motion
- Prefer one purposeful system (GSAP) for scroll story
- No universal fade-up
- Reduced-motion: opacity only ≤150ms

## Voice
- Specific, technical, honest — no invented metrics
- Internship-open without hype

## Anti-patterns banned here
- Fake terminal chrome
- Glass cards without interaction need
- Sky/purple glow fields
- Chip soup / proficiency bars
- Identical project card layouts
- Decorative spinning 3D
